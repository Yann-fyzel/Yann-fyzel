# Salut, moi c'est Yann, Ingénieur Logiciel & Cybersécurité

Développeur de formation, je conçois des outils avec un fort accent sur la propreté du code, l'optimisation et les architectures de sécurité. Mon objectif est de bâtir des systèmes résilients et de concevoir des solutions DevSecOps.

### Stack Technique & Compétences
- **Langages :** Rust, TypeScript, JavaScript, C#, C++, Dart
- **Frameworks :** Next.js, React.js, React Native, Flutter, .NET MAUI, Avalonia .NET, Node.js
- **Backend & APIs :** Fastify, Express.js, REST APIs
- **Réseau & Infrastructures :** Cisco LAN/NAT, routage OSPF/BGP, architectures EVE-NG
- **Focus Sécurité :** Cybersécurité, développement d'applications sécurisées, outils Red Team / Blue Team

### 📁 Projets Actifs & Portfolio
- **Log-Sentinel-CLI (Rust) :** Un service démon asynchrone qui surveille les journaux système en temps réel, détecte les signatures d'attaques applicatives (SQLi, XSS, Path Traversal) et transmet les métadonnées via HTTP/JSON.
- **Consultation de Chantier (Flutter) :** Application mobile permettant le suivi en temps réel de l'avancement des projets à partir des données de synthèse des gestionnaires.

### ⏳ Projets à Venir
- **SecureTransfer (Rust / C#) :** Application cross-platform (Mobile & Desktop) sécurisée et optimisée pour le transfert rapide de fichiers.
